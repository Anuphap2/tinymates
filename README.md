## 🌟 Overview (เกี่ยวกับโปรเจกต์)

**TinyMates** คือเว็บแอปพลิเคชันช่วยจับเวลาอ่านหนังสือและทำงาน (Pomodoro Timer) ที่ผสมผสานความน่ารักของสัตว์เลี้ยงเสมือนจริง (Virtual Pets) เข้ากับดีไซน์เรียบหรูสไตล์ **ElevenLabs Editorial Aesthetic** ช่วยสร้างบรรยากาศที่สงบ มีสมาธิ และไม่น่าเบื่อ

ทุกนาทีที่คุณตั้งใจโฟกัส คุณจะได้รับเหรียญ (Coins) เพื่อนำไปปลดล็อกสัตว์เลี้ยงตัวใหม่ ตกแต่งห้องธีมต่างๆ และมิกซ์เสียงบรรยากาศ (Ambient Soundscapes) ได้ตามใจชอบ

## ✨ Key Features (ฟีเจอร์เด่น)

### ⏱️ 1. Editorial Pomodoro Timer
- ตัวเลขนับถอยหลังขนาดใหญ่ สบายตาด้วยฟอนต์คลาสสิกสไตล์แมกกาซีน (**EB Garamond**)
- ปรับโหมดจับเวลาได้อย่างรวดเร็ว:
  - **Focus Mode:** 25 นาที (รับ 100 เหรียญเมื่อจบ และ +5 เหรียญทุกนาที)
  - **Short Break:** 5 นาที
  - **Long Break:** 15 นาที
- แถบความคืบหน้า (Progress Hairline) แบบมินิมอล

### 🐾 2. Interactive Virtual Pets (สัตว์เลี้ยงแสนน่ารัก)
โมเดลสัตว์เลี้ยง 2D ถูกเรนเดอร์อย่างคมชัดระดับ Retina (High-DPR) ด้วย Canvas Engine:
- 🐱 **Mochi (แมวส้ม):** หนวดแมวสองข้าง หางเรียวยาวพริ้วไหว ตาวาวประกายสองชั้น
- 🐕 **Latte (ชิบะ):** หูตั้งทรงสามเหลี่ยม ปากยิ้ม ขนหน้าอกสีครีม และหางม้วนดุ๊กดิ๊ก
- 🦆 **Duckie (เป็ดน้อย):** จงอยปาก 3D ปีกกระพือได้ และเท้าว่ายน้ำ
- 🐰 **Bunny (กระต่าย):** หูกระต่ายยาวเด้งตามแรงฟิสิกส์ และหางปุกปุย
- 🐷 **Babe (หมูชมพู):** หูพับ จมูกหมู 3D และหางขดสุดกวน
- **Interactive Actions:**
  - **Cuddle & Pet:** คลิกที่ตัวน้องเพื่อลูบ น้องจะเต้น/กระโดดอย่างดีใจ พร้อมกระจายหัวใจ ❤️ และลอยเหรียญ `+10 🪙`
  - **Treat Feeding:** คลิกที่พื้นว่างเพื่อหย่อนขนมคุกกี้ 🍪 น้องๆ จะเดินมาเคี้ยวตุ้ยๆ
  - **Living Animations:** หายใจ, กระพริบตา, เดินเตาะแตะ, นั่งพัก, และนอนหลับพร้อมละออง Zzz

### 🏠 3. Customizable Cozy Rooms (แต่งห้องได้หลากสไตล์)
- **Daylight:** ห้องโมเดิร์นคลีนๆ แสงแดดอุ่นส่องผ่านหน้าต่าง
- **Warm Sunset:** บรรยากาศยามเย็นแสงสีส้มทอง
- **Starlight:** ห้องนอนกลางคืนเงียบสงบพร้อมท้องฟ้าจำลอง
- **Garden & Park:** สวนธรรมชาติกลางแจ้ง ต้นไม้และทุ่งหญ้าพริ้วไหว
- **Kitchen, Bedroom, Cafe, Boho:** ห้องครัว, คาเฟ่มินิมอล และห้องสไตล์โบฮีเมียน

### 🎵 4. Multi-Track Ambient Audio Deck
- เครื่องเล่น **Lo-Fi Music** พร้อมแถบกราฟิก Equalizer Waveform เต้นตามจังหวะเพลง
- เปิดผสมเสียงบรรยากาศธรรมชาติได้สูงสุด 3 เสียงพร้อมกัน:
  - 🌧️ ฝนตกพรำๆ (Rain) พร้อมอนิเมชันละอองฝนและระลอกน้ำบนพื้น
  - 🔥 กองไฟอบอุ่น (Campfire) พร้อมสะเก็ดไฟลอย
  - 🌊 คลื่นทะเลซัดสาด (Ocean Waves)
  - 🦗 จิ้งหรีดยามค่ำคืน (Night Crickets) พร้อมหิ่งห้อยเรืองแสง
  - 🎧 โฟกัสเข้มข้น (White Noise)

### 🤖 5. Mindful Companion Chat (AI เพื่อนคู่คิด)
- แชทคุยเพื่อขอกำลังใจ หรือขอคำแนะนำการพักสายตากับสัตว์เลี้ยง
- มีปุ่ม Quick Prompts ให้กดถามได้ทันที
- รองรับทั้งการเชื่อมต่อ **Google Gemini API** และมีระบบ **Local Fallback** ตอบข้อความภาษาไทยอัตโนมัติอย่างอบอุ่นแม้ไม่มี API Key

### 📝 6. Focus Checklist (To-Do List)
- จดบันทึกงานที่ต้องทำในแต่ละรอบโฟกัส
- ติ๊กถูกพร้อมแถบแสดงสถานะความคืบหน้า (Progress Counter)

## 🎨 Design Philosophy (ปรัชญาการออกแบบ)

แอปพลิเคชันนี้ออกแบบโดยอิงตามแนวทาง **ElevenLabs Design System** (`DESIGN.md`):
- **Base Canvas:** โทน Off-White (`#f5f5f5`) สะอาดตา ไม่ปวดตา
- **Ink Primary:** ปุ่มแคปซูลสีหมึกเข้ม (`#292524`)
- **Atmospheric Gradient Orbs:** ลูกแก้วแสงเฉดพาสเทลละมุน (Mint, Peach, Lavender, Sky) ลอยอย่างสงบนิ่งในฉากหลัง
- **Hairline Elegance:** กรอบการ์ดบางเฉียบ 1px (`#e7e5e4`) พร้อมเงา Soft Drop Shadow

## 🛠️ Tech Stack (เทคโนโลยีที่ใช้)

| Layer | Technologies |
|---|---|
| **Core Framework** | React 19.2 + Vite 7.2 |
| **Styling** | Vanilla CSS Tokens + Tailwind CSS v4 |
| **Graphics & 2D** | HTML5 Canvas API (Custom High-DPR Physics Engine) |
| **Audio** | Web Audio API (Procedural Buffers & Multi-track Mixer) |
| **Icons** | Lucide React |
| **Storage** | SecureStorage (AES Local Encryption) |
| **AI Integration** | Google Gemini API (with Local Fallback Persona) |

## 🚀 Getting Started (วิธีติดตั้งและเปิดใช้งาน)

### ข้อกำหนดเบื้องต้น
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป)
- Git

### 1. โคลนโปรเจกต์
```bash
git clone https://github.com/Anuphap2/tinymates.git
cd tinymates
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. ตั้งค่า Environment Variables (ทางเลือก)
สร้างไฟล์ `.env` ที่โฟลเดอร์หลัก หากต้องการใช้ Google Gemini API สำหรับระบบแชท:
```env
VITE_GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```
*(หากไม่ใส่ API Key ระบบจะใช้คำตอบอัตโนมัติของน้องสัตว์เลี้ยงแทน สามารถเล่นได้ตามปกติ)*

### 4. รันโหมด Development
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:5173`

### 5. Build สำหรับ Production
```bash
npm run build
```
